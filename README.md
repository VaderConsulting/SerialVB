# SerialVB

Working copy of OpenNETCF.Samples.SerialVB from Dave Robinson's Historical Dev archive: a Pocket PC VB.NET serial terminal that opens COM4 via OpenNETCF.IO.Serial 1.3 (`Serial.dll` at the repo root). Visual Studio 2003 `SerialVB.sln` contains only the Pocket PC deploy project `SerialVB.vbdproj`; the sample source is `Form1.vb`.

**Source last updated:** 2004-01-08  
**Language:** VB.NET  
**Target:** Pocket PC

## How to open

Open `SerialVB.sln` in Visual Studio 2003 (Smart Device / Pocket PC).
